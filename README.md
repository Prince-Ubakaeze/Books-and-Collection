## 🚀 How to Use This Repository

1.  **Clone the repository** to your local machine:
    ```bash
    git clone 
    ```
2.  **Navigate** to the specific category folder using your file explorer or terminal.
3.  **Open the files** using your preferred PDF, EPUB, or Markdown reader.

## 🤝 Contributing

Contributions to this collection are welcome! If you have a book or resource you would like to add:

1. Fork the repository.
2. Create a new branch (`git checkout -b add-new-book`).
3. Place your file in the appropriate directory.
4. Commit your changes (`git commit -m 'Add [Book Title] by [Author]'`).
5. Push to the branch (`git push origin add-new-book`).
6. Open a Pull Request.

*Please ensure all contributed resources are free of copyright restrictions or fall under the public domain.*
